<feature>
  <name>Simulation engine unit tests</name>
  <files>tests/test_sim_engine.py, tests/test_sim_noise.py</files>
  <behavior>
    Deterministic tests (test_sim_engine.py):

    1. test_load_route_sets_stopped_state
       - load_route([(57.0,11.0),(57.01,11.01)]) -> engine.state == SimState.STOPPED

    2. test_load_route_too_few_waypoints_raises
       - load_route([(57.0,11.0)]) -> raises ValueError

    3. test_play_transitions_to_playing
       - load_route -> play() -> state == SimState.PLAYING

    4. test_pause_freezes_position
       - load_route -> play() -> tick(0.05)*20 -> pause()
       - frame_a = tick(0.05), frame_b = tick(0.05)
       - assert frame_a.lat == frame_b.lat and frame_a.lng == frame_b.lng
       NOTE: noise is applied on output — use same random seed via random.seed(42) before each tick pair.
       Easier approach: assert state is PAUSED and speed == 0 in both frames.

    5. test_stop_resets_to_first_waypoint
       - load_route([(57.0,11.0),(57.01,11.01)]) -> play() -> tick(0.05)*50 -> stop()
       - engine._lat == 57.0 and engine._lng == 11.0 (check internal state, not noisy frame)

    6. test_heading_lag_converges
       - load_route([(57.0,11.0),(57.0,11.1)]) — pure east bearing ~90 deg
       - play() -> run 200 ticks at dt=0.05
       - assert engine._heading is within 5 degrees of 90.0 after convergence

    7. test_route_completes_auto_stops
       - load_route([(57.0,11.0),(57.000001,11.000001)]) — tiny segment
       - play() -> run 500 ticks at dt=0.05, cruise_speed=100.0 (fast)
       - assert engine.state == SimState.STOPPED after ticks complete

    8. test_bearing_helper_east
       - _bearing(0, 0, 0, 1) ≈ 90.0 (east) within 1 degree

    9. test_angle_diff_wraps_correctly
       - _angle_diff(10, 350) == 20.0  (shortest path crosses 0)
       - _angle_diff(350, 10) == -20.0

    10. test_haversine_known_distance
        - _haversine_m(0, 0, 0, 1) ≈ 111_195 metres (1 degree of lng at equator) within 500m

    Statistical test (test_sim_noise.py):

    11. test_noise_is_nonzero_across_ticks
        - load_route -> play() -> collect 200 frames at dt=0.05
        - Extract lat values from all PLAYING frames
        - Compute std dev of lat values
        - Assert std_dev > 0 (noise is non-zero)
        - Assert std_dev < 0.001 (noise is small — not wildly wrong sigma)

    12. test_noise_values_vary_between_runs
        - Two separate SimEngine instances, same route, same ticks
        - Collect frame.heading from 50 PLAYING ticks each
        - Assert the two sequences are NOT identical (non-deterministic)
        NOTE: probability of collision is astronomically low given float noise.
  </behavior>
  <implementation>
    Write tests directly using pytest. No mocking needed — SimEngine is pure Python.
    Import helpers directly: `from ghost_drone.simulation.engine import _bearing, _angle_diff, _haversine_m`
    For test_pause_freezes_position: check frame.state == SimState.PAUSED and frame.speed == 0.0
    rather than comparing noisy lat/lng values across ticks.
    Run: uv run pytest tests/test_sim_engine.py tests/test_sim_noise.py -v
  </implementation>
