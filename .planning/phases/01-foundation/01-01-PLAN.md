    - `AppConfig` is a `@dataclass` with three `str` fields
    - `load_config() -> AppConfig` exits via `sys.exit(message)` (not `raise`) on: file not found, TOML decode error, missing keys
    - Each error message names the specific problem and tells the user what to do

    **`ghost_drone/startup.py`**

    Implement two functions:

    `probe_zenoh(endpoint: str) -> None`:
    - Follow RESEARCH.md Pattern 3
    - Use the short-timeout JSON5 config variant from Pitfall 1:
      ```python
      conf_str = (
          f'{{"connect": {{"endpoints": ["{endpoint}"]}}, '
          f'"transport": {{"unicast": {{"open_timeout": 3000}}}}}}'
      )
      ```
    - Catch `Exception` broadly (exception type not documented in zenoh 1.x)
    - Hard exit via `sys.exit(message)` if open fails

    `print_startup_banner(cfg: AppConfig, host: str, port: int) -> None`:
    - Follow RESEARCH.md Pattern 6
    - `PHASE_SUBJECTS = ["heading_true_north_deg"]` — the one subject used in the round-trip test helper (Plan 02)
    - Check each subject via `keelson.is_subject_well_known()`
    - Print a 60-char `=` border top and bottom
    - Print: zenoh endpoint, realm, entity ID, server URL
    - If any subjects are unrecognised, print a `WARNINGS:` block inside the banner with `[UNKNOWN SUBJECT]` prefix on each line — WARNING ONLY, the process continues (user decision overrides roadmap criterion 4)
    - Use `display_host = "127.0.0.1" if host == "0.0.0.0" else host` for the URL

    **`ghost_drone/server.py`**

    Implement Pattern 4 from RESEARCH.md:
    - `STATIC_DIR = Path(__file__).parent.parent / "static"` — resolves to the project-level `static/` directory relative to the installed package file
    - `app = FastAPI(title="ghost-drone")`
    - Mount `StaticFiles(directory=STATIC_DIR, html=True)` at `"/"` as the LAST (and only) mount — after any future API routes
    - No lifespan handler in Phase 1; browser open happens in `__main__.py`

    **`ghost_drone/__main__.py`**

    Implement Pattern 1 from RESEARCH.md:
    - `argparse` with `--host` (default `"0.0.0.0"`) and `--port` (type=int, default `8000`)
