  <name>Task 1: RollPitchModel sinusoidal oscillator</name>
  <files>ghost_drone/simulation/roll_pitch.py</files>
  <action>
Create ghost_drone/simulation/roll_pitch.py with the RollPitchModel class.

The class tracks elapsed simulation time (_elapsed_s) and computes sinusoidal roll and pitch with Gaussian noise on each tick.

Class interface:
- __init__(): set defaults: roll_amplitude_deg=5.0, roll_period_s=10.0, pitch_amplitude_deg=3.0, pitch_period_s=8.0, noise_sigma_deg=0.5, _elapsed_s=0.0
- reset() -> None: zeroes _elapsed_s. Call when simulation stops.
- tick(dt: float, state: SimState) -> tuple[float, float]: advances _elapsed_s by dt ONLY when state is SimState.PLAYING. Returns (roll_deg, pitch_deg) computed as:
    roll = roll_amplitude_deg * math.sin(2 * math.pi * _elapsed_s / roll_period_s) + random.gauss(0, noise_sigma_deg)
    pitch = pitch_amplitude_deg * math.sin(2 * math.pi * _elapsed_s / pitch_period_s) + random.gauss(0, noise_sigma_deg)
  Return roll and pitch even when PAUSED or STOPPED (keeps last oscillation point frozen).

All five public attributes (roll_amplitude_deg, roll_period_s, pitch_amplitude_deg, pitch_period_s, noise_sigma_deg) are mutable — the server wiring plan will update them from browser settings.

Do NOT import from ghost_drone.server or ghost_drone.zenoh_bridge — this module is pure simulation, no cross-package dependency.
  </action>
  <verify>uv run python -c "from ghost_drone.simulation.roll_pitch import RollPitchModel; from ghost_drone.simulation.models import SimState; m = RollPitchModel(); r, p = m.tick(0.05, SimState.PLAYING); print('roll:', r, 'pitch:', p); m.reset(); print('elapsed after reset:', m._elapsed_s)"</verify>
  <done>Import succeeds, tick() returns two floats, reset() zeroes _elapsed_s without error.</done>

  <files>ghost_drone/zenoh_bridge/telemetry.py</files>
  <action>
Create ghost_drone/zenoh_bridge/telemetry.py with these exports:

1. MPS_TO_KNOTS = 1.94384  (CRITICAL: SimEngine produces m/s, speed_over_ground_knots subject expects knots)

2. encode_timestamped_float(value: float) -> bytes
   - Create TimestampedFloat from keelson.payloads.Primitives_pb2
   - msg.timestamp.FromNanoseconds(time.time_ns())
   - msg.value = value  (note: proto float32, 1e-3 tolerance in tests)
   - return keelson.enclose(msg.SerializeToString())

3. encode_location_fix(lat: float, lng: float) -> bytes
   - Create LocationFix from keelson.payloads.foxglove.LocationFix_pb2
   - msg.timestamp.FromNanoseconds(time.time_ns())
   - msg.latitude = lat; msg.longitude = lng; msg.altitude = 0.0
   - return keelson.enclose(msg.SerializeToString())

4. make_key(cfg: AppConfig, subject: str, source_id: str) -> str
   - return keelson.construct_pubsub_key(base_path=cfg.keelson_realm, entity_id=cfg.entity_id, subject=subject, source_id=source_id)
   - Import AppConfig from ghost_drone.config

5. class SubjectThrottle:
   - __init__: self._last: dict[str, float] = {}
   - should_publish(subject: str, rate_hz: float) -> bool:
     if rate_hz <= 0: return False
     period_s = 1.0 / rate_hz
     now = time.monotonic()
     if now - self._last.get(subject, 0.0) >= period_s:
         self._last[subject] = now; return True
     return False
   - reset() -> None: self._last.clear()  — call on simulation stop

Imports needed: time, keelson, from keelson.payloads.Primitives_pb2 import TimestampedFloat, from keelson.payloads.foxglove.LocationFix_pb2 import LocationFix, from ghost_drone.config import AppConfig.

Do NOT call zenoh directly — this module only builds bytes and key expressions. ZenohPublisher.publish() is called by the server.
  </action>

print('All assertions passed')
